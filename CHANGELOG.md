# Changelog

## 1.0.0 — Initial release

- Accounts and open sessions in separate dashboard sections, with visible CPU controls, PID, version and resource usage.
- Ordered launch queues, saved destinations, groups and presets.
- Game discovery, search, favorites and a server browser that preserves results when rate-limited.
- Native friends with counts, communities and an expandable avatar editor with rotatable 3D previews, a complete body palette and illustrated outfit controls.
- Progressive lists, account-scoped caching and bounded parallel loading for games, friends, outfits and avatar previews.
- Automatic saving for local appearance, language, animation, CPU, graphics, audio, notification and local API preferences.
- Nine themes, scalable text, responsive layouts and lightweight motion.
- Roblox version selection, crash reconnection, window arrangement and verified manager updates.
- Optional schedules, recordings, vault/import, local API, Nexus and scoped JavaScript tools.
